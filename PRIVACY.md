# Privacy

Guides, cases, and reviewed notes are stored as local JSON in the app's sandbox. No account, analytics, advertising, third-party SDK, application backend, or ticket-provider connection is present. The app does not send tickets or customer communications.

Optional suggestions use Apple's on-device SystemLanguageModel. The selected issue, bounded guide excerpts, and optional photo are supplied only after an explicit action. There is no Private Cloud Compute or external-provider fallback. Apple governs model eligibility and readiness.

Selected photos are copied as bounded JPEGs without the source metadata. They are not included in saved case records. Removing a photo or leaving the workspace removes the working copy; an abrupt termination may leave a temporary file until the operating system purges it. Original photos remain unchanged.

There is no encrypted-export feature, remote backup, or collaboration. Protect confidential case data with the device's normal security settings. Public tests and screenshots contain original synthetic examples only.
